# Color Clash

Color Clash is a competitive Roblox game where players are divided into teams based on their actions. The game features a plain map with white boxes as the ground and some boxes on the floor. When the game starts, every player is teleported to a line, and one player is chosen to freeze for 10 seconds. During this time, other players can run and color the boxes blue by touching them. After the chosen player unfreezes, they can color the boxes red, and any player they touch joins their team. The game lasts for 5 minutes, and the team that colors the most boxes wins. There is also a lobby area, and the waiting time for the next round is 40 seconds.

## Install

1. Download the project files from the GitHub repository.
2. Open the Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. In the Roblox Studio, navigate to the `ServerScriptService` folder. If it doesn't exist, create it.
5. Place the following scripts in the `ServerScriptService` folder:
   - `BoxColoring.server.lua`
   - `GameManager.server.lua`
   - `LobbyManager.server.lua`
   - `PlayerManager.server.lua`
6. Ensure that the workspace has the necessary parts and models for the game to function correctly.

## Use

1. Start the Roblox game.
2. Players will be automatically teleported to the lobby area.
3. After the waiting time, the game will start, and players will be teleported to the game area.
4. One player will be chosen to freeze for 10 seconds.
5. Other players can run and color the boxes blue by touching them.
6. After the chosen player unfreezes, they can color the boxes red, and any player they touch joins their team.
7. The game lasts for 5 minutes, and the team that colors the most boxes wins.
8. After the round ends, players will be teleported back to the lobby area for the next round.
